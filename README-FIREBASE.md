# Descendentes RPG — Firebase

A página inicial permanece vazia.

O projeto usa:
- Firebase Realtime Database para os dados e para o cadastro/login administrativo personalizado (sem Firebase Authentication).
- Fotos de notícias processadas no navegador (redimensionadas/comprimidas) e salvas como Base64 no próprio Realtime Database.

Não é necessário ativar o Firebase Storage para o módulo de notícias.

Limite configurado para a imagem final: aproximadamente 350 KB.
